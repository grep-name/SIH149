to build the project you can use the command depengin on your operating system:

## Windows:

    required tools - MinGW-w64 (MSYS2)

    command - "cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release"

## linux or macos

    required tools - gcc or clang

    command - "cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build"


## NOTE
all the built binaries will be placed inside build folder by default.
