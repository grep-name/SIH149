Sanitization

This is irreversible. On SSDs a firmware Purge is preferred; host-level overwrite cannot reach over-provisioned or retired blocks.

Secure file & folder erasure

Free-space wipe

Fills every unallocated cluster, then releases it — this is what destroys the content of files deleted before FORGE was installed. Directory-entry and MFT record padding is included.

Forensic recovery

The source is opened read-only for the whole operation; FORGE never writes to evidence media. Each recovered object is hashed at extraction time.
